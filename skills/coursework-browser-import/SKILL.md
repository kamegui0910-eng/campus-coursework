# 浏览器辅助课程导入

先读项目STATE.json与docs/BROWSER_IMPORT.md。用户在真实学校页完成登录和MFA，助手使用现有会话；不要收集密码，不把Cookie、浏览器配置、登录截图或会话状态发给模型或上传GitHub。

本版复用browser-extension/collector.mjs做确定性读取，无逐步模型调用。固定流程是核对账号→课程发现→用户选课程→采集→导出→Coursework预览→明确确认→按当前登录账号导入。学校登录过期暂停并引导本人重登；没有取得内容时记录缺口，不重复尝试登录密码。

扩展适用于电脑Chrome/Edge；云端站点接收导出包，尚未提供手机远程登录浏览器。开发电脑关机不影响已经上传的资料，但不会让本地采集继续执行。

变更前查现有代码和官方文档，只加载相关模块；已有PDF/DOCX提取、不可变资料版本、任务去重、评分试算和同步Skill直接复用。不同学校平台单独适配，不能仅换网址就说已支持。

测试collector的分页/会话过期/账号变化、导入的用户隔离/重复导入/缺口保留。浏览器导入是用户提供的快照，不能独立证明学校身份或正式提交；不把客户端声明当学校签名结果。源版本、mock测试、实际浏览器、真实学校分别记录。

需要跨设备接续时使用skills/cloud-local-sync/SKILL.md。源码可公开，实际导出包、学校资料与任何会话都不能进入仓库。
