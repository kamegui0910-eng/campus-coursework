# 接收者使用自己的模型与API

本包传递可执行的工作指令、参考和模板；由接收者自己的智能体宿主加载，并使用该宿主已接通的模型与工具。模型ID、账号、额度、学校登录、检测许可和提交授权各自独立。接入不要求更换到作者的供应商，也不复制作者的订阅会话。

## 选择实际接入方式

1. **已有支持skills/文件与工具的智能体客户端**：将整个文件夹放入该客户端当前支持的skill目录，或允许其读取本文件夹，再交给它 `START_FOR_AI.txt`。在客户端已有的模型设置中选择本人模型/API；不修改本skill里的模型名来假装已切换宿主。
2. **自建智能体已有API适配器**：按适配器真实契约配置provider、Base URL、确切模型ID与凭据引用，将 `SKILL.md` 作为可发现的任务指令，并保证能按相对链接读取参考/模板。宿主负责对话、工具调用、文件持久化、浏览器与调度；不能把整套工具只写在提示词里就声称它们可执行。
3. **只有普通文字聊天API**：可读取提供给它的材料、解释或起草，但没有天然的学校登录、文件保存、排程或提交能力。先列缺少的智能体执行层；保留可完成部分，不能承诺仅填API地址就完成全流程。若接收者要求另建宿主/适配器，再作为明确的实现任务处理，按其接口和凭据规则配置并测试。

不要假定不同供应商都支持同一种API路径。`openai-compatible-chat`、`openai-responses`、供应商原生协议或本地模型接口按实际宿主支持填写；这些是记录标签，不是本包已实现的网络适配器。保持用户指定的模型ID；`supports_tools`、联网、图像、JSON输出等能力均要按可核验接口/实际结果判断，不从模型名称推断。

## 私人运行配置

按 [runtime.example.json](../assets/runtime.example.json) 建立工作目录下 `coursework/runtime.json`。模板默认 `host_managed`，不创建新API调用。只有接收者明确要求独立API调用、宿主确实提供适配器，且凭据/费用路径已按其环境要求处理，才使用 `external_api`。

记录：宿主名称与版本、local/cloud位置、模型连接方式、供应商和确切模型ID（可见时）、不含认证参数的Base URL、协议标签、环境变量名/凭据槽位引用、实际adapter引用、工具可用性与核验时间、工作目录及验收结果。密钥值、Cookie和token永不写入模板、skill、报告或分享包；只有环境变量名并不表示密钥已存在或调用成功。

模型已经在客户端正常工作时优先复用本人选择；不额外创建付费API，不替接收者选择供应商。需要新API配置时读取当前环境适用的凭据技能和工具规则；检测到凭据存在不等于获准使用，不把学校文本当作首次测试输入。

## 功能与工具逐项对应

| 功能 | 需要核验的实际能力 | 缺失时 |
|---|---|---|
| 读取skill、资料和保留进度 | 文件读取、工作目录持久写入、读取相对参考 | 只处理实际提供的资料，报告未保存项 |
| 找大纲和当前作业 | 已授权学校连接器，或可操作且已核验登录的浏览器 | 完成已取得材料的整理，标记访问缺口 |
| 每课资料库与按作业取材 | 持久文件/索引、内容哈希、官方课程身份、版本和章节依赖；可用本包辅助脚本 | 按同一契约用宿主文件工具维护；不能声称仅安装skill已自动下载资料 |
| 读取PDF/教材/图表 | 正文提取、必要页面查看和授权阅读器 | 不声明已完整阅读未取得的内容 |
| Word/PDF正式成稿 | 文件制作与真实逐页渲染 | 交付可用草稿，格式未核验不放行 |
| 分工与最终审计 | 实际委派工具，或显式分阶段执行 | 可以顺序兼任，不能虚构独立worker |
| 按真实正文词数选站审计 | 少于300词需Copyleaks，达到300词需Copyleaks与Turnitin；本人合法提交前报告和实际浏览器/连接器 | 本稿必需站缺失则待审，不用缺失结果当低分；Copyleaks自身输入要求仍须满足 |
| 定时推进 | 真实调度器、持久状态及可用执行环境 | 交付计划/提示词，不能说已设置 |
| 正式提交 | 本人有效授权、当前版本审计放行、真实平台操作与回执 | 保留成果和缺口，不标Submitted |

可以用不同工具实现同等能力，Computer Use不是对所有宿主都可安装的通用API名称。若使用Windows，则按当前可用Computer Use技能；其他宿主用其官方支持的浏览器工具。没有工具执行循环的模型API不能独自完成表中动作。

## 首次验收

先做无需学校账号和模型外发的本地检查：完整skill与相对资源能读取、模板可解析、能在本人工作目录写入再读取测试文件；不创建排程或提交。输出 `coursework/setup-report.json`，按每项能力记录 `unknown/available/verified/unavailable`、证据和时间，区分“宿主声明支持”与“实际操作成功”。不得因配置模板写了true就标verified。

按 [课程资料库](course-library.md) 验证课程隔离、同名任务不同章节的取材、修订后待复核和失败恢复；测试夹具与真实学校结果分别记录。脚本的文件/索引测试不能替代实际 syllabus/rubric 下载和教材阅读。云端读不到本地文件时，给出正规手动上传与归属验证步骤，不声称已同步。

若本人已要求验证独立API连接，先按当前环境规则取得相应授权/凭据选择；用不含个人资料的短请求验证指定模型一次，保存实际provider/model、成功或错误、时间及用量（未知如实记），不自动换供应商或重试付费请求。没有验证就写not_run，不凭HTTP地址或目录列表声称模型可用。已在宿主运行的当前对话可记录host_active，不冒充另一个API endpoint测试。

随后仅按接收者授权逐项验证学校访问、完整大纲读取、文件渲染、按真实正文词数选定的检测报告与调度。少于300词只要求Copyleaks但须符合其自身输入要求；达到300词而无Turnitin交前AI报告、必需站不支持文本或缺调度器都在验收中单列，不能用服务不可用冒充长度例外。部分可用不标“完整流程已接通”。创建排程和正式提交仍遵守主skill独立条件。

换设备时用原分享包在新环境重新核验工具、账号与路径，不能沿用作者机器的能力结论。更新只替换skill，保留私人资料和授权；确认新版本的检测/审计条件后再恢复相关任务。

## 云端的准确含义

云盘ZIP是交接载体，在线模型API是推理服务，智能体宿主是执行流程的环境；分别记录其位置和状态。本包没有上传模型权重、训练模型或部署推理服务器，也不转交作者的运行进程。需要云端可调用的工具时，使用接收者已经授权且真实存在的服务，不将作者的本机localhost写成远程接口。

OpenAI文档当前说明：Codex Cloud可读取仓库内skills，本机个人skills不自动同步，且当前不提供Computer/Browser Use。此限制针对该环境，其他云端环境逐项检查，不扩大推断。[官方Cloud environments](https://learn.chatgpt.com/docs/environments/cloud-environments)。文档核对日期：2026-11-06；未来以实际能力与当前文档为准。
