# 作业文本生成时的skill调用清单

此表规定各worker何时实际读取相应skill，不表示所有技能在每个阶段都执行。先读项目AGENTS、题干/rubric和本skill，再按当前任务选择必要项。已安装且适用的技能须实际读取其当前入口与要求的参考；未读不记录applied，不因总控或另一worker曾读过就声称本worker已读。

| 阶段 | 本环境中的技能名称 | 适用条件与实际动作 |
|---|---|---|
| 课程与作业总控 | `campus-coursework` | 读取主入口及当前阶段参考；负责大纲、真实要求、分工、状态与审计交接 |
| 英文起草、修改与压缩 | `anti-defensive-writing-en` | 起草/修订前读取；用明确论点、证据匹配、集中结构与自然表达组织内容 |
| 中文起草、修改与压缩 | `anti-defensive-writing` | 中文任务读取；与英文版按实际作业语言选择，不机械同时加载两版 |
| 学校页面、教材阅读器、检测站和提交网页 | `computer-use:computer-use` | 确有浏览器/Windows操作、且合适连接器不能完成时，读取当前技能和必要操作指导；纯离线编辑不强行开浏览器 |
| 制作、修改Word文件及排版核验 | `documents:documents` | 生成/修改DOCX时读取；依当前工具制作、真实渲染并逐页检查，保留版式证据 |
| 读取/生成/核验PDF | `pdf:pdf` | 对PDF进行实际提取、制作或版式核验时读取；有图表/OCR缺口时核对页面；不凭文本抽取声称视觉排版已验证 |

技能名称可能随接收者宿主而不同，选择其真实可用的同等能力并记录实际名称/来源。不要在未核实的客户端里声称这些插件已安装。`skill-creator`用于维护本包，模型接入/开发技能用于相应配置任务，不是每份作业的固定写作步骤；普通作业也不无故加载图像、网站开发或营销技能。

## 技能缺失时

本包已在 [writing-and-submission.md](writing-and-submission.md) 内嵌清晰论点、结构、证据、语言与必要事实/局限原则。接收者没有Anti-Defensive技能时可依这些规则继续，并记录 `embedded_guidance`，而不是假称已读完整外部skill。

Computer Use、Documents、PDF等外部技能与执行工具的完整实现没有随本包捆绑。接收者可使用真实等效浏览器、连接器或文档工具；记录实际方法和证据。缺少必要学校访问、正文读取或渲染能力时保留对应缺口，不能仅用提示词替代实际操作或因使用了内置规则就放行。

Anti-Defensive的叙事建议以具体学校要求、事实、来源、必要反思、局限及矛盾发现为边界，不隐藏不利证据、不虚构优势。实际作业使用本人的真实观点和材料，不把任何写作skill当作作者身份或检测结果证明。

## 评分参考与格式规则

学校rubric、APA7、Times New Roman12pt、双倍行距和syllabus-first是要求/偏好，不是假装存在的独立skill。项目如有适用的 `UOTP_Writing_Rubric_AA50.md`，Assignment起草前完整读取并核对目的与读者、组织、发展与分析、语言四项最高标准；具体课程/作业rubric优先。

朋友使用自己学校的量表和格式。包内四项通用写作检查可补充使用，但没有捆绑作者学校完整AA50文件，也不把其评分权重套到其他学校。

## 每稿记录实际应用

在本稿quality record中保存 `skill_usage`，最终审计引用或复核同一份记录。每项至少写：

- `skill`：技能名或本包内置参考名。
- `status`：`applied`、`embedded_guidance`、`not_needed`或`unavailable`。
- `source_reference`：实际读取的文件/资源或当前等效工具引用；未读时null。
- `read_at`：本worker实际读取时间；未读时null。
- `application_or_reason`：本稿采用了什么规则、完成什么操作，或为何不适用/不可用；需要操作证据时附结果路径。

只有真实读取并按本稿任务应用才能记 `applied`。单纯发现元数据、模板列出了名字、总控说“已使用”或存在旧稿记录都不够。普通离线润色可将Computer Use记 `not_needed`；需要DOCX排版但无渲染工具则记 `unavailable`并保留版式缺口。记录为空表示没有提供实际应用证据，不能自动当全部技能已用或全部失败。

记录与当前稿件版本一起交给最终审计。修订worker补充本轮实际应用，不覆盖既有历史；不要把内部skill清单、调用日志或质量记录附进正式作业，除非题目要求。
