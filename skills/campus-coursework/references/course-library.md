# 每门课的资料库与作业取材

本参考用于首次建课、同步课程资料、手动补文件和向作业 worker 交接材料。资料库保存在使用者的私人工作目录，不写入 skill 或分享包；已有课程资料可建立索引复用，不要求搬动或重新下载合法副本。

## 课程身份与保存范围

以已核验的学校正式域名、平台、官方 course ID、学期和 section 区分课程；显示标题和教材书名不能作唯一键。同名课程、重修课和不同学期各有独立目录。课程库至少能定位以下实际存在的材料：

| 材料 | 需要保存或记录 |
|---|---|
| 官方 syllabus | 原件或完整官方网页正文、来源和版本、完整读取覆盖、课程政策与周表 |
| rubric | 通用课程量表与各项作业具体量表分别保存，注明适用任务 |
| 教材 | 核验书目和版次；合法本地原件，或授权阅读入口、实际已读笔记与缺口 |
| 周模块/课堂 | 已发布的讲义、附件、录像入口与可保存材料、真实课堂笔记；标周/模块与时间范围 |
| 每项作业 | 完整题干、附件、指定阅读、研究来源、教师更新和来源绑定 |

已发布且允许下载的材料应实际保存；网页材料保存完整正文及稳定来源。教材仅允许在线阅读时，记录在线阅读限制，保存合法自写笔记、章节/节/页/图表定位与实际覆盖，不能写成整本教材已下载。不要把目录、登录页、启动页或空文件当成原文。

私人目录中的 `courses/<identity-derived-dir>/library.json` 是资料和作业依赖的索引；原件、文字提取、笔记、草稿和审计仍可按现有目录保存。可以使用 [本地资料库辅助脚本](../scripts/course-library.mjs) 管理索引，具体输入与用法见 [辅助脚本说明](course-library-helper.md)；它辅助文件与依赖记录，不替代真实学校访问、正文核验或阅读。

## 资料索引与版本

每份资料保留稳定的来源 ID/链接、所属课程、资料类型、适用任务/周/模块、教材版次、章节/节/页/图表或录像时间范围，以及核验时间。每个保存版本记录本地路径、内容哈希、来源修订信息和实际取得时间；新版本保留旧版，不用同名文件静默覆盖历史证据。来源 URL 只保留稳定入口，不保存临时签名、OAuth code、Cookie 或 token。

分别记录发布/访问、保存和读取：可打开阅读器不表示已下载；文件已保存不表示已读；已有章节笔记不表示图表、精确引用和章末题都已覆盖。部分读取只复用明确覆盖的范围。OCR/提取内容与原件相关联，不能把不完整提取当全文。

同一来源再次同步时，先核对实际修订信息或实际内容。文件名未变而正文/量表变了仍是新版本。字节相同只能说明保存的该文件未变，不能证明其他模块未更新。仅本地检查时记录本地检查，不更新为“学校实时复核”。

## 全量采集与按进度补充

可以选择一次采集全部**已发布、已授权且允许保存**的材料，或先采集当前及即将到期作业所需材料，再随进度补充。两种方式都遵守 syllabus-first：完整大纲先建立课程基线，之后才计划和派发内容工作。未发布的周/附件记 `not_published`，不是下载失败，不从大纲自行补造实际题干。

每次开始作业和每次定时运行均检查该任务真实题干/rubric、公告、指定章节、附件及个人截止更新；同步新发布或修订的相关材料。全量采集不代表以后无需同步。没有新材料时复用已核验版本，避免无依据重复下载。共享资料由指定资料负责人写索引，其他 worker 交付新增/变更请求，避免并发覆盖。

## 同名作业与精确资料绑定

任务身份用官方 assignment/topic/外部活动 ID 和 component 区分，周/模块、标题和 chapter 是任务标签与要求，不能只按标题匹配，也不因老师改标题自动新增重复任务。主帖、必要回复和不同平台活动保留各自身份及映射。

为每项任务建立“题干要求 → 资料 ID 与版本 → 具体使用范围”的依赖记录，并保留证明该绑定的真实要求来源。例如两次都叫 Weekly Summary，第一项指定 Ch4、另一项指定 Ch5，就分别绑定各自任务 ID、对应教材版次及章节、当周真实课堂/视频和适用 rubric。不得把上周资料包改名后当本周已完成。

派发时生成该项作业的资料包：完整题干和具体 rubric、适用课程政策、明确版本的相关教材片段/笔记、真实课堂材料、研究来源和缺口。只读取所需部分，不把整门课程或整本教材全部塞进上下文。跨章节任务可明确绑定多个范围；章节不明、教材版次冲突或必需附件缺失时先核验，不用相邻章节或别门课材料填补。

使用辅助脚本时，定位标签按记录的确切范围匹配；它不会从“读过 Ch4”自动推导某张图表或全部页码已核验。资料的课程归属、正文验证和阅读证据必须来自实际核查，不能只为生成 Ready 资料包而填写成功字段。rubric 单独提供、嵌在题干或老师未提供均如实记录；未知不能冒充无需量表。

资料/题干/rubric 更新后，记录哪些依赖任务受到影响，把其旧资料包、已有草稿和最终审计标为需复核或 Stale，再核对内容与重新放行。原文件和审计历史保留；无关任务不应全部重做。已经正式提交的任务只记录更新影响，不自动重交。

## 下载失败与手动恢复

先区分学校下载、保存到本地、以及云端/模型资料区上传这几个阶段。保存失败不等于学校没有文件，云端上传失败也不抹掉已保存的本地副本。每次事件记录目标资料/任务、失败阶段、实际页面或工具证据、原因确定程度、通俗说明、稳定入口、恢复动作和待核验项；仅在有新依据时重试，避免循环刷同一错误。

| 实际观察 | 给使用者的说明示例 | 恢复动作 |
|---|---|---|
| 返回学校登录页 | “学校账号还没登录进去，这次拿到的是登录页面，不是课程文件。” | 从正式学生入口登录后回到原课程文件 |
| 页面明确要求手机/双重验证 | “学校需要你在手机上确认这次登录，确认后我才能继续下载。” | 由本人在正规登录界面完成验证；不要在聊天发验证码 |
| 已登录但明确无权限/文件锁定 | “账号已登录，但这份文件目前没有给你开放。” | 记录显示的开放条件/时间；请本人在学校页面核查权限 |
| 老师尚未发布 | “这周的资料还没发布，暂时没有文件可下载。” | 标未发布，后续同步；继续可用工作 |
| 授权阅读器可读但无官方导出 | “教材能在线阅读，目前这个入口没有提供文件下载。” | 在线阅读并保存合法笔记与定位，不要求违规导出 |
| 超时/断网，原因未确认 | “下载没有完成，目前只看到连接超时，还不能确定是网络还是学校页面的问题。” | 保留原入口，核查连接后按实际证据重试或手动下载 |
| 本地已存但云端上传失败 | “文件已经下载到本机，但还没传进当前云端任务。” | 保留原件；用该任务正式附件/资料入口手动上传后核验 |

人工指引必须说清：打开哪个稳定学校页面 → 点击哪个文件/菜单 → 需要下载哪份原件/哪一版 → 保存到哪个课程的待导入位置或当前任务的正规附件入口 → 完成后如何继续。无法确定按钮名称时如实描述已见页面，不编造点击路径；若需本人现场辨认，可请其按正式页面下载所指文件。

人工导入后先核验非空、可打开、实际正文、课程/学期/教材版次、来源和适用任务，计算哈希并入库，再读取所需范围。错课文件、登录 HTML 或未知版本不能自动解除原缺口；记录拒收原因和需要补的正确资料。只有恢复成功且经过核验才关闭该事件，不能把“已给用户指引”写成“下载成功”。
