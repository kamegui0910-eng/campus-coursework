# 课程与作业总控 skill

此包复用“登录学校系统 → 读取完整课程大纲 → 每课独立资料库 → 按作业取相关章节 → 教材与作业分工 → 定时更新推进 → 统一最终审计 → 必要修改/复检 → 授权提交 → 回执核验”的方法。它包含可移植指令、私人配置与审计模板、worker 提示词及本地资料索引辅助脚本，不包含任何人的账号、学校资料、作业、模型或既有自动化。

## 给接收者

**发给朋友时，直接发送完整ZIP。朋友解压后，先把 `START_FOR_AI.txt` 交给能读取该文件夹的智能体。** 包里包含完整SOP、来源/写作/排程/审计参考、配置模板和worker提示词；朋友自行连接自己的模型/API、学校及检测账号。

把整个 `campus-coursework` 文件夹放入支持 skills 的 Codex 环境。当前官方文档列出的用户级目录是 `~/.agents/skills/`，项目级目录是项目下 `.agents/skills/`；如你的应用已经使用另一受支持的 skill 目录，可按其当前说明安装，避免同名双份。目录下应直接存在 `campus-coursework/SKILL.md`，不要多套一层同名文件夹。未出现时重启应用或重新打开会话。

也可在已允许访问该文件的环境中直接给出 SKILL.md 路径并要求按该 skill 执行。普通聊天不一定能读取本机文件或加载本地 skills；应使用确实支持所需技能和工具的环境。安装路径与产品能力以当前官方文档为准：[Build skills](https://learn.chatgpt.com/docs/build-skills)。

朋友的模型供应商不必与作者相同。先按 [自有模型接入说明](references/portable-runtime.md) 检查宿主及工具，在其已有客户端/智能体设置中填自己的供应商、Base URL、确切模型ID和凭据引用。`assets/runtime.example.json` 是空白交接模板，不是会自动发请求的API适配器；密钥在本人本机环境或宿主凭据管理器中配置，不贴进skill或发给作者。仅有聊天API时，还需可执行工具的智能体宿主，才能登录网页、读写文件和定时运行。

首次调用示例：

```text
使用 $campus-coursework。我的学校入口是 [学校正式网址]。
先核验我本学期的在读课程，完整保存并读取每门课的官方 syllabus，
再按真实作业要求建立分工和定时推进流程。缺账号登录时让我在学校页面完成。
先给我可审阅的成果；需要提交时依据我的明确授权。
```

若希望持续自动提交，可以在课程范围明确后给出这类指令：

```text
对刚才核验的 [具体课程/学期]，定时推进讨论和论文作业。
在学校允许的辅助范围内，所有必需内容与质量检查完成后自动提交，
并保存真实回执。该授权到 [日期] 为止；测验、考试、重交和联系他人另行处理。
```

这只是本人可采用的授权措辞，不是模板替任何人预先授权。接收者用自己的模型账号、额度、学校账号、工具和资料，独立建立私人配置与授权。

## 每门课的资料库

资料库按 [每课资料库与作业取材](references/course-library.md) 管理：syllabus、课程/作业rubric、教材或授权阅读笔记、周模块、课堂和作业附件分别保留来源与版本。同名作业按官方ID绑定确切章节和当周材料；一次收集全部已发布内容或随进度补充都可以，每次作业仍核对新发布与修订。只交接本项相关资料，更新后复核受影响稿件和审计。下载/上传失败给通俗原因及具体手动下载/导入指引，验证通过后才标恢复。

## 最终审计 SOP

所有写作任务先回同一个最终审计职责，逐项检查题干、rubric、真实来源、学生观点、引用、学校要求与渲染，再按真实符合条件的正文词数选择检测站：**少于300词仅Copyleaks，达到300词Copyleaks与Turnitin；本稿所有必需站都严格低于20%**。记录真实词数、计数范围/方法/证据和选站理由；20%不通过，必需站未知或不支持也不通过，生成模型不能自评代替检测。检测不代替原创性、学校政策或提交授权检查。

审计智能体使用环境实际支持的专用浏览器会话，或按当前 Computer Use技能操作；本包没有另行捆绑浏览器引擎、检测账号或API服务。检测不通过时退回具体意见，按真实材料修订，保存差异并重新检测，默认最多三轮；仍未满足则保留待审。报告和放行绑定确切文件/文本版本，改稿后重新审计。

接收者须自行配置本稿所需检测站的合法账号、文本处理授权及提交前报告入口。短讨论/回复不足300词时Turnitin依长度例外不要求，但Copyleaks自身最低长度/语言要求仍须满足；不满足则保留待审，不拼接无关文本。达到300词的稿件若Turnitin仅有交后报告或无权限仍不能放行，不能冒充短文本例外或先交后补检。详见 [最终审计](references/final-audit.md) 与 [站点说明](references/detector-standards.md)。

## 能力条件

- 需要真实学校访问能力；浏览器/Windows 工作需要可用的 Computer Use 或足够的连接器。
- Word/PDF 成稿需要制作与逐页渲染能力；没有工具时会报告未核验项。
- 定时执行需要真实调度器；本地文件、skill 与桌面浏览器依赖机器和应用运行、会话有效。云端不能自动继承本机登录。[Scheduled tasks](https://learn.chatgpt.com/docs/automations?surface=app)
- skill 不包含自建网站、API服务、统一收费入口或云端托管，也不保证任何特定模型账号可用。本地脚本辅助资料文件、版本和依赖索引；学校访问、下载与阅读仍使用调用环境的实际工具，不能把索引测试当真实下载测试。

无需安装原作者的全部个人技能：本包已写入关键阅读、写作、证据和授权规则；可用时再调用当前 Computer Use、文档/PDF 和相应语言的 Anti-Defensive Writing 等专门技能。

具体阶段与技能名见 [写作skill调用清单](references/skill-routing.md)：英文/中文起草分别读取相应Anti-Defensive Writing，网页操作读取Computer Use，Word/PDF制作读取Documents/PDF。已安装且适用时须实际读取；没有时记录内置规则或等效工具，不能声称调用了不存在的skill。每稿质量记录和最终审计保留实际应用情况。本包包含调用路由和核心规则，不捆绑这些专门插件的完整实现。

## 分享前检查

仅分享这份干净 skill 文件夹/ZIP，不把使用后产生的 `coursework/` 一起打包。不要附带 profile/grants、登录会话、教材、真实课程文件、同学内容、成绩或提交证据。接收者应遵守自己学校的真实政策，作者的历史授权不会传递。

本包为流程资产，不会自动启用课程任务。只有实际调度器返回并经核验的任务才算已设置，只有真实平台回执才算已提交。

每版包可附 `PACKAGE_MANIFEST.json` 供接收者核对文件数量、大小与SHA-256；它是完整性清单，不是数字签名。先核验干净副本，再建立自己的私人配置。后续更新替换skill文件，保留本人 `coursework/`，检测策略或内容有变化时按审计规则使旧放行失效。

“发到云盘供下载”和“云端执行”分别核验。此包可经本人选择的渠道发给朋友；保存ZIP不等于云端已运行，也没有自动双向同步。Codex Cloud当前文档说明仓库中的skill可供云任务读取，本机个人skill不会自动同步，且该环境当前不提供Computer/Browser Use；其他云端宿主按其实际能力检查。[Cloud environments](https://learn.chatgpt.com/docs/environments/cloud-environments)
